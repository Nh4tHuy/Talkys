Cấu Hình Gemini API Key

Kết nối chìa khóa trí tuệ nhân tạo Google

Hướng Dẫn Lấy Gemini API Key Miễn Phí

  1. Truy cập Google AI Studio: https://aistudio.google.com/app/apikey
  2. Đăng nhập bằng tài khoản Google (Gmail) của bạn.
  3. Bấm nút "Create API Key" → Sao chép chuỗi ký tự API Key.
  4. Dán chuỗi API Key vào ô nhập phía trên và bấm "Lưu Thiết Lập".

* Mọi xử lý chìa khóa được lưu bảo mật 100% trong bộ nhớ duyệt web cá nhân (LocalStorage) của bạn.

Hướng Dẫn Nhanh

1

Nhập Google Gemini API Key miễn phí tại góc phải hoặc bảng bên trái.

2

Nhập văn bản kịch bản hoặc tải tệp PDF / Word (.docx, .doc) vào ô soạn thảo.

3

Chọn giọng đọc, phong cách và nhấn nút "Tạo Giọng Đọc AI".
